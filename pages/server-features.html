Server Features & Command Reference

Both Liberty servers (Standard MIX and Racing) run a suite of advanced Lua scripts to enhance gameplay, moderation, and team management. Below you will find a complete list of features, player commands, and admin tools. Additional scripts are active only on the MIX or Racing server as noted.

Common Scripts (Both Servers)

  • AFK System - Auto-detects idle players, issues warnings, and kicks after timeout. Manual AFK toggle with immunity for higher admins.
  • Alias System - Tracks player aliases by IP and game hash. Supports fuzzy name search and pirate detection.
  • Deployable Mines - Press Flashlight (default F) to plant proximity mines from allowed vehicles (driver seat). Mines explode on enemy contact.
  • Grenade Capacity - Dynamically adjusts max/starting grenades per map and gametype (e.g., limits shotguns to 1 frag).
  • Next Game - Instantly cycles to the next map in rotation.
  • Team Shuffler - Auto-balances teams after a set number of games. Manual shuffle command available.
  • Uber Transport - Call a ride from teammates by typing uber, taxi, cab, or taxo in chat. Driver approval optional.

MIX‑Server Exclusive Scripts

  • Name Ban - Automatically kicks players who join with a disallowed name (e.g., "Butcher", "Nigga", "LIB-Descono", etc.).
  • Seat Mod - Allows gunners or passengers to take the driver seat when empty and moves passengers to gunner seat when a driver is present.

Racing server omits these two scripts for a pure racing experience.

Racing‑Server Exclusive Scripts

  • Track Master - Advanced racing tracker & leaderboard. Records personal bests, map records, global rankings, checkpoint validation, and lap time announcements. Commands: /stats, /top, /global, /reset.
  • Race Assistant - Enforces vehicle usage in race modes. Grants a grace period then issues escalating penalties (kill, kick) if players remain on foot.
  • Vehicle Spawner - Map‑aware vehicle spawning with custom keywords per track (e.g., hog, rhog, quad). See /vlist for available vehicles.

These scripts make the racing server competitive and fair - no name bans or seat swapping.

Admin Tips:
  • Alias database persists across server restarts (saved to sapp/aliases.json).
  • Uber transport respects team rules - you can only call vehicles from teammates.
  • Deployable mines: requires vehicle_only mode (default) - works in warthogs, ghosts, rocket hogs, mongooses, and many custom vehicles.
  • Team shuffler works only in CTF, Slayer, Oddball, King - never in FFA or race modes.
  • Track Master global rankings use a weighted system: map record +200, global record +300, performance up to +50, and top finishes as tiebreakers. Players with fewer than 3 maps played receive a 50% penalty.
  • Race assistant gives 30 seconds to enter a vehicle; after violations, it escalates from warnings → kill → kick. Forgiveness period of 30 seconds of continuous racing resets violations.
  • Vehicle spawner cooldown is shared across all keywords; despawn timer starts when the vehicle is empty. Use /vlist to discover map‑specific vehicles (e.g., custom hogs on bc_raceway_final_mp).
