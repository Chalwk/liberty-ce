Server Features & Command Reference

MIX SERVER

  • Rank System (View Leaderboard)
    Progression system (Recruit → General). Earn credits per kill, lose credits on death. Streak bonuses, first blood bonus, and rank announcements. Persistent stats saved between games.
  • Uber Transport
    Call a ride from teammates.
  • Game Modes
    Team Slayer, CTF, King of the Hill, Oddball with varying kill limits, flag captures, and weapon sets (rockets, shotguns, classic, all weapons).

RACE SERVER

  • Track Master (View Leaderboard)
    Advanced racing tracker & leaderboard. Records personal bests, map records, global rankings, checkpoint validation, and lap time announcements.
  • Uber Transport
    Call a ride from teammates.
  • Proximity Mines
  • Laps to Win
    Races require 5, 10, or 15 laps depending on track.

📋 Command Reference

Available on both servers
uber, taxi, cab, taxo
CHAT
Call a nearby teammate's vehicle (driver required) by typing keyword in chat. Cooldown and call limits apply.
/help
CMD
Show available commands.
MIX-server exclusive commands
/rank
Show your current rank, grade, credits, kills/deaths/KDR, and progress to next rank.
/ranks
List all available ranks and their credit thresholds (Recruit through General).
/top
Show top players by total credits earned (MIX leaderboard).
Racing-server exclusive commands
Flashlight key
KEY
Deploy a proximity mine from a vehicle while in the driver seat.
/vlist
CMD
List all available vehicle spawn keywords for the current map.
hog, rhog, quad
CHAT
Summon a vehicle and automatically enter the driver seat by typing keyword in chat. Some maps have specific keywords. Use /vlist to view available keywords.
/stats [player|all]
CMD
Show your personal best lap, average lap time on the current map, or view another player's stats.
/top [page]
CMD
Display the paginated leaderboard of best lap times on the current map.
/global [page]
CMD
Show global overall player rankings across all race maps.
/reset
CMD
Reset your current checkpoint back to the starting checkpoint.
